# Data Acquisition and Management Coursework

This repository contains coursework, projects, and hands-on assignments completed for the **Data Acquisition and Management** course.

## Course Overview

In a world where organizations collect data of increasing complexity and scale, organizing and managing that data is the first step toward creating value. This course introduces core database management topics and practical data workflows.

Key areas include:

- Understanding the difference between data and information from a data-centric perspective
- Managing data with and without databases
- Computer and data security fundamentals
- Data cleansing, fusion, and processing techniques
- Data integration across multiple sources
- Storage approaches for very large datasets
- Database privacy and security considerations

## Hands-On Focus

This course emphasizes practical experience. Throughout the term, students build multiple databases by:

- Importing complex datasets
- Cleaning and transforming data
- Manipulating and organizing data for analysis
- Storing data effectively
- Applying security best practices

The work also emphasizes critical thinking and creativity in designing efficient and effective data management solutions.
